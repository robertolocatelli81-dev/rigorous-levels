# Security policy

Please report vulnerabilities **privately**, not in a public issue or pull request:
use GitHub's "Report a vulnerability" button on the Security tab of this repository (private vulnerability reporting).

Useful in a report: the file and function, an input that shows the problem, what you expected and what happened,
and the commit you tested.

In scope: an interval marked GARANTITO that does not contain the true eigenvalue of the stated H; an input that should
be refused and is accepted; a crash or hang on untrusted input; a secret written where it should not be.

Not a vulnerability, but welcome as a public issue: a wrong number with a non-OK state, a slow case, a missing feature.

There is no bug bounty.

Supported versions: only the latest commit of the default branch until a first release is published.
